# CHALÉ LIFE — Phase 2 Art Direction & Character Style Bible

## 1. Core Visual Identity
**Target Direction:** *Polished Stylized 3D Contemporary Ghanaian Life Sim*

- **Setting:** Contemporary urban/residential Accra (Osu, Adabraka, East Legon, Labone visual cues).
- **Atmosphere:** Warm coastal West African sunlight (`#FFF3D6` key light), soft sky fill (`#DCEBFA`), warm laterite earth bounce (`#D9B38C`), and clean architectural silhouettes.
- **Color Language:**
  - **Architectural Base (60%):** Sun-baked cream plaster (`#F6E3BA`), sand-washed concrete (`#CBD5E1`), warm terracotta plinths (`#B45309`), and weathered asphalt (`#334155`).
  - **Cultural & Commercial Surfaces (30%):** Provision kiosk cobalt/sky blue (`#0284C7` / `#38BDF8`), telecom/signboard gold (`#FACC15`), terracotta roofing (`#9A3412`), tropical neem/mango foliage (`#15803D`).
  - **High-Intent Accents (10%):** Kente gold-amber (`#F59E0B`), emerald (`#059669`), pepper-red (`#DC2626`).
- **Strictly Prohibited:** Safari/hut clichés, generic tribal masks, cyberpunk neon, anime proportions, hyper-realistic uncanny textures, or mismatched low-poly asset-store primitives.

## 2. Character Style Standard (`PLAYER_GHA_001` & NPC Archetypes)
All human characters in **CHALÉ LIFE** share a unified rig, proportion scale, and material response:

| Parameter | Standard Specification |
| :--- | :--- |
| **Total Height** | `1.74m` (standard adult), `1.68m`–`1.76m` archetype range |
| **Origin / Pivot** | `(0, 0, 0)` centered between feet on the ground plane; local `+Z` is forward |
| **Head-to-Body Ratio** | `1 : 6.2` (stylized life-sim proportion with expressive facial readability) |
| **Eye Placement** | `Y = 1.53m`, `Z = +0.135m`, `X = ±0.052m` with sclera, dark brown iris, upper lid, and brows |
| **Hand Proportions** | `0.09m × 0.11m × 0.05m` sculpted palm mit + thumb silhouette |
| **Foot Proportions** | `0.11m × 0.08m × 0.24m` contoured sneaker/sandal/loafer with distinct sole welt |
| **Skin Material** | `roughness: 0.54`, `metalness: 0.04` — warm deep Ghanaian skin tones (`#5C3317`, `#6B3E26`, `#4A2511`, `#7A482B`) |
| **Hair Material** | `roughness: 0.82`, `metalness: 0.02` — sculpted tapered fade, braided crown, twists, or salt-and-pepper trim |
| **Cloth Material** | `roughness: 0.68`, `metalness: 0.02` — procedural canvas weave & contemporary Ghanaian textile trim |
| **Rig Hierarchy** | `Root -> Pelvis -> Torso -> Head`, `ShoulderL/R -> ElbowL/R -> HandL/R`, `HipL/R -> KneeL/R -> FootL/R` |
